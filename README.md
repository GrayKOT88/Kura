# Kura: Рефакторинг и улучшение архитектуры мобильной игры

> Реальный игровой проект, прошедший путь от монолитного прототипа до структурированного приложения с применением современных паттернов проектирования. Цель — показать навыки рефакторинга, оптимизации и организации кода в коммерчески доступной игре.

## 🎯 О проекте

**Kura** — это моя первая самостоятельная игра, опубликованная на платформе "Яндекс Игры". Изначально код был написан "в лоб" и представлял собой спагетти-код. В этом репозитории представлена **переработанная версия**, где я применил полученные знания для улучшения архитектуры.

🔗 **Ссылка на игру:** [Kura на Яндекс.Играх](https://yandex.ru/games/app/333765?lang=ru)

📌 **Цель проекта:**
- Показать эволюцию моего подхода к разработке.
- Продемонстрировать применение ключевых паттернов в реальном проекте.
- Создать основу для дальнейшего развития игры (добавление контента, оптимизация).

## 🧩 Ключевые архитектурные изменения

В процессе рефакторинга были применены следующие паттерны и подходы:

| Паттерн/Подход | Применение | Решаемая проблема |
| :--- | :--- | :--- |
| **DI / IoC (Zenject)** | Внедрение зависимостей во все ключевые сервисы и менеджеры. | Устранил жесткую связанность классов. Код стал гибким и тестируемым. |
| **Object Pooling** | Управление спавном цыплят и лис. | Повысил производительность за счет переиспользования объектов вместо постоянного Instantiate/Destroy. |
| **Finite State Machine (FSM)** | Управление искусственным интеллектом лисы. | Заменил сложную логику на понятную и расширяемую систему состояний. |
| **Событийная модель** | Система подсчета очков, обновления UI и реакция на действия игрока. | Избавился от постоянных проверок в `Update()`. Код стал более реактивным и производительным. |
| **ScriptableObject** | Хранение настроек игры и баланса. | Позволяет легко изменять параметры игры без редактирования кода. |
| **DOTween** | Анимация UI-элементов (появление, исчезновение, эффекты). | Обеспечил плавную анимацию с минимальной нагрузкой на производительность. |

## 🛠 Использованные технологии и возможности Unity

- **Zenject:** Для внедрения зависимостей.
- **DOTween:** Для анимации UI.
- **Object Pooling:** Для оптимизации.
- **Классическая FSM:** Для управления ИИ.
- **UI Toolkit / Canvas:** Для создания пользовательского интерфейса.
- **Мини-карта:** Реализована как дополнительная функция.

## 🚀 Запуск проекта

1.  Убедитесь, что установлен Unity Hub и редактор Unity версии **2021.3 LTS** или выше.
2.  Клонируйте репозиторий.
3.  Откройте проект через Unity Hub, выбрав корневую папку `Kura`.
4.  Откройте сцену `Scenes/MainGame.unity` и нажмите кнопку Play в Unity Editor.
